# Configuration

## Imported settings

The recipe imports `iconify_icons.settings` with one icon collection enabled:

| Collection key | Pack |
|---|---|
| `mdi` | Material Design Icons |

The recipe enables only the `mdi` collection. To use icons from other packs, enable their
collections in the Iconify Icons settings.

## Changing the settings

Manage the icon collections from the Iconify Icons settings in the administration interface.

## Field, menu, and editor settings

Each UI Icons module provides its own settings for fields, menus, CKEditor 5, and text
formats. See the project pages for the current options:

- [UI Icons](https://www.drupal.org/project/ui_icons)
- [Iconify Icons](https://www.drupal.org/project/iconify_icons)
